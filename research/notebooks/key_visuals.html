Reading guide¶

Read each explanation before its code cell. Run from top to bottom in the documented working directory. A saved chart is an output snapshot, not proof that this notebook was rerun today. The final section collects findings and visual evidence.

Method¶

Duplicate rows are removed. Stratified training, validation and test partitions separate learning from model selection. Preprocessing is fitted within pipelines. Validation average precision selects the model and a recall constraint selects its threshold.

Interpretation limits¶

A validation recall constraint does not guarantee test or future recall. Random partitions do not demonstrate future-period generalization. Retention effectiveness requires an intervention study.

Guide to code step 4¶

Summarize observations. Grouping collects rows with the same label. Counts and sums produce totals; a mean of a binary 0/1 indicator gives a rate. Always identify the denominator and keep missing categories visible.

Create comparable bands. cut uses fixed boundaries; qcut attempts equal-sized quantile groups. Tied values can reduce the number of groups. Compare both observed rates and the number of records in each band.

Read the chart. The axis labels identify units and the grouping defines what is compared. A visual association does not establish cause. Rate charts need denominators; truncated axes can exaggerate small differences.

predictions["risk_band"] = pd.qcut(predictions["churn_probability"], 10, duplicates="drop")
bands = predictions.groupby("risk_band", observed=True).agg(
    Customers=("actual", "size"),
    ObservedChurnRate=("actual", "mean"),
    AverageScore=("churn_probability", "mean"),
).reset_index()
figure, axis = plt.subplots(figsize=(10, 5))
axis.plot(range(1, len(bands) + 1), bands["ObservedChurnRate"], marker="o", label="Observed")
axis.plot(range(1, len(bands) + 1), bands["AverageScore"], marker="o", label="Predicted")
axis.set(title="Churn Risk Deciles", xlabel="Risk decile", ylabel="Rate")
axis.legend()
axis.grid(alpha=0.25)
figure.tight_layout()
